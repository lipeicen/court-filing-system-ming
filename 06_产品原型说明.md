## 二、核心页面

### 2.1 案件创建页

步骤导航:
```
[1.基本信息] -> [2.当事人] -> [3.材料] -> [4.确认]
```

基本信息:
- 案由: [下拉选择]
- 案件类型: [一审/二审/再审]
- 管辖法院: [省] [市] [区] [法院]
- 标的金额: [输入框] 元
- 适用程序: [普通/简易/小额]

当事人信息:
- 原告/申请人:
  - 类型: [自然人/法人]
  - 姓名/名称: [输入]
  - 证件号码: [输入] [OCR识别]
  - 地址: [输入]
  - 电话: [输入]
- 被告/被申请人: [同上]
- 代理人:
  - 姓名: [输入]
  - 律所: [输入]
  - 执业证号: [输入]

### 2.2 材料上传页

上传区域:
```
+--------------------------------------------------+
|                                                  |
|     [拖拽文件到此处 或 点击上传]                  |

```

## 三、交互设计

### 3.1 智能提示

输入联想:
```
当事人姓名: [张]
           +--------+
           | 张三   |
           | 张四   |
           | 张五   |
           +--------+
```

案由选择:
```
案由: [民间借贷]
      +------------------+
      | 民间借贷纠纷     |
      | 借款合同纠纷     |
      | 金融借款合同纠纷 |
      +------------------+
```

### 3.2 批量操作

批量选择:
```
+------+----------+----------+
| [v]  | 案件1    | 待提交   |
| [v]  | 案件2    | 待提交   |
| [ ]  | 案件3    | 审核中   |
| [v]  | 案件4    | 待提交   |
+------+----------+----------+

[批量提交] [批量导出] [批量删除]
```

### 3.3 异常处理

提交失败:
```
+------------------------------------------+
| 提交失败                                  |
+------------------------------------------+
| 原因: 验证码识别失败                      |
|                                          |
| [重试] [切换手动输入] [稍后重试]         |
+------------------------------------------+
```

材料不合规:
```
+------------------------------------------+
| 材料校验不通过                            |
+------------------------------------------+
| 起诉状.pdf:                              |
|   [x] 文件大小超过50MB (当前: 65MB)      |
|   [x] 缺少原告签名                        |
|                                          |
| [压缩文件] [重新上传] [跳过此项]         |
+------------------------------------------+
```

## 四、响应式设计

### 桌面端 (1920x1080)
- 左侧边栏固定
- 内容区自适应
- 表格完整展示

### 笔记本 (1366x768)
- 左侧边栏可折叠
- 表格横向滚动
- 卡片布局调整

### 平板 (1024x768)
- 左侧边栏隐藏
- 汉堡菜单
- 单列布局
